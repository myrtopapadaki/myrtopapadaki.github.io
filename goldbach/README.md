# myrtopapadaki.github.io

---

Επεξήγηση του τρίτου σκέλους της εργασίας HW0.

---

Αρχικά, χρησιμοποίησα long long, αντί για int, προκειμένου να μπορεί το πρόγραμμα να δέχεται αριθμούς, εντός του εύρους που ζητήθηκε.

Έφτιαξα μια συνάρτηση, που να ελέγχει αν ένας αριθμός είναι πρώτος.
Δέχεται λοιπόν έναν αριθμό και ξεκινώντας από τον αριθμό 2 (ο πρώτος **πρώτος** αριθμός), τον διαιρεί με όλους τους αριθμούς μέχρι και τη ρίζα του, για να βρει αν το πηλίκο είναι 0. Αν είναι, τότε δεν είναι πρώτος. Επίσης, αν βρεθεί κάποιος διαιρέτης, διακόπτονται οι διαιρέσεις που ακολουθούν, για εξοικονόμηση χρόνου.

Επίσης, έφτιαξα και μια ακόμα συνάρτηση που ελέγχει για έναν αριθμό την εικασία του Goldbach.
Θέτω δύο μεταβλητές, στις οποίες θα τοποθετηθούν οι δύο πρώτοι αριθμοί. Με μια επαναληπτική διαδικασία, αναζητώ τους αριθμούς αυτούς, με τον πρώτο να είναι ο μικρότερος δυνατός.

Τέλος, στη main τοποθέτησα τα περισσότερα μηνύματα εξόδου, καθώς και τις ερωτήσεις που απευθύνονται στον χρήστη.
Το πρόγραμμα ξεκινάει ζητώντας έναν αριθμό. Αφού τον διαβάσει, ελέγχει αν είναι έγκυρος, αλλιώς εμφανίζει κατάλληλο μήνυμα. Εφόσον είναι, ρωτά τον χρήστη πως θέλει να συνεχίσει. Ανάλογα με την επιλογή του, μεταφέρει τον αριθμό που διάβασε στην κατάλληλη συνάρτηση.
